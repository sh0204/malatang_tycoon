# 🍲 마라탕 타이쿤 (Malatang Tycoon)

몰입감 있는 1인칭 요리 시점으로 즐기는 마라탕 가게 운영 시뮬레이션 게임입니다.  
플레이어는 마라탕 가게의 주인이 되어, 손님이 가져온 재료 바구니를 확인하고 취향에 맞는 최고의 마라탕을 만들어 서빙해야 합니다.

---

## ✨ 주요 특징

- **1인칭 조리 시점**  
  카운터 너머의 손님과 직접 소통하며 요리하는 플레이 방식으로, 실제로 가게를 운영하는 듯한 몰입감을 제공합니다.

- **따뜻한 핸드 드로잉 아트**  
  텍스트를 최소화하고 아이콘과 부드러운 색감의 스케치 스타일 UI를 사용해, 직관적이고 따뜻한 분위기를 지향합니다.

- **마라탕 특화 시스템**  
  재료 바구니 확인, 무게 측정(추가 예정), 맵기 조절 등 실제 마라탕 매장의 프로세스를 게임 메커니즘으로 녹여냈습니다.

- **언어 장벽 없는 UI**  
  한글·영어 같은 텍스트 중심 설명 없이도, 시각적 요소만으로 누구나 쉽게 이해하고 플레이할 수 있도록 설계되었습니다.

---

## 🛠 기술 스택

- **Framework**: Flutter  
- **Game Engine**: Flame Engine  
- **Language**: Dart  
- **IDE**: Trae (AI-Native IDE)

---

## 📂 화면 구성 (UI Layout)

- **Top Area**  
  손님이 등장하고, 주문 말풍선과 표정 등을 통해 피드백을 표현합니다.

- **Center Area**  
  조리용 냄비, 재료 바구니, 작업대 등이 배치되며 실제 요리 액션이 이루어지는 메인 플레이 영역입니다.

- **Bottom Area**  
  맵기 단계 선택, 조리 관련 액션 버튼 등이 위치하여 플레이어가 직접 조작하는 컨트롤 영역을 구성합니다.

## 🚀 시작하기

### 1. Flutter SDK 설치 확인

Flutter가 로컬 환경에 설치되어 있어야 합니다.  
설치가 필요하다면 공식 문서를 참고해 Flutter SDK를 먼저 설치하세요.

### 2. 저장소 클론

```bash
git clone https://github.com/sh0204/malatang_tycoon.git
cd malatang_tycoon
```

### 3. 패키지 설치

```bash
flutter pub get
```

### 4. 프로젝트 실행

```bash
flutter run
```

원하는 플랫폼(모바일, 데스크톱 등)에 맞춰 디바이스를 선택한 뒤 실행하면 됩니다.
